# Вариант 11. Сервис дисциплин (Discipline Service)

## Описание сущности
Уникальные комбинации параметров: name + code (Название дисциплины должно быть уникальным в сочетании с её кодом).

---

## Добавить дисциплину
Информация, требуемая для создания дисциплины:

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :--- | :--- | :--- | :--- | :--- | :--- |
| name | Полное название (н-р, Математика) | Да | String | Unique, Max 255 | - |
| code | Код (н-р, ОГСЭ.01) | Да | String | Unique | - |
| is_active | Статус использования | Нет | Boolean | - | True |

Информация, возвращаемая при удачном создании:
| Параметр | Тип |
| :--- | :--- |
| id | Integer |
| name | String |

---

## Изменить дисциплину по ID
Параметры запроса:

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
| :--- | :--- | :--- | :--- | :--- |
| name | Новое название | Нет | String | Max 255, Unique |
| code | Новый код | Нет | String | Unique |
| is_active | Новый статус | Нет | Boolean | - |

Информация, возвращаемая при удачном изменении:
| Параметр | Тип |
| :--- | :--- |
| id | Integer |
| status | String |

---

## Удаление дисциплины по ID
Возвращает True, если поле is_active успешно установлено в False. Сама запись остается в базе данных для сохранения истории.

---

## Получить дисциплину по ID
Возвращаемая информация:
| Параметр | Пояснение | Тип |
| :--- | :--- | :--- |
| id | Идентификатор | Integer |
| name | Название дисциплины | String |
| code | Код | String |

---

## Получить список сущностей по параметрам
| Параметр | Пояснение | Тип | Описание |
| :--- | :--- | :--- | :--- |
| name | Поиск по названию | String | Частичное совпадение |
| is_active | Фильтр по статусу | Boolean | Только активные/неактивные |

Возвращается список объектов со столбцами:
| Параметр | Тип |
| :--- | :--- |
| id | Integer |
| name | String |
| code | String |
